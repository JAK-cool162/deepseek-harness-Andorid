Third-party software in the DeepSeek Harness Android app
========================================================

Bundled in the APK
------------------

node-addon-require-builtin (assets/native-addons/*/node-addon-require-builtin-android-*)
  The published package's C++ source, compiled for Android by
  apps/android/scripts/build-android-addons.sh at the commit it records.
  License: MIT
  Source:  https://github.com/deepseek-ai/dsh-node-addon-require-builtin

@deepseek-ai/node-addon-system flock addon (assets/native-addons/*/node-addon-system-android-*)
  This repository's native/system/packages/entry/src/flock.c, compiled for
  Android by the same script.
  License: MIT

Downloaded at install time, not bundled
---------------------------------------

The full engine downloads, when the user installs it, prebuilt Android
packages from the Termux repository (https://packages.termux.dev): bash,
coreutils, findutils, grep, sed, gawk, diffutils, tar, gzip, xz-utils, less,
procps, dash, curl, ca-certificates, Node.js (nodejs-lts), npm, git, gh,
Python, and their libraries. Each keeps its own license; the build recipes
and license files are at https://github.com/termux/termux-packages, and each
package installs its license under share/doc/<package>/ in the engine's
prefix. It then installs the published @deepseek-ai/dsh npm package and its
dependencies.
